Phương án 1: Sidecar Container (Khuyên Dùng)

Do kiến trúc Coolify tự phát hành dưới dạng mã nguồn Laravel đóng gói và thường xuyên tự động cập nhật (Auto-update), việc can thiệp trực tiếp vào mã nguồn cốt lõi (Core Laravel) của Coolify sẽ làm mất đi khả năng tự động cập nhật hoặc gây xung đột cơ sở dữ liệu.

Giải pháp tốt nhất: Triển khai một Web GUI & Daemon độc lập chạy song song dưới dạng Docker container sidecar.

Nguyên lý hoạt động của Sidecar Module:

  • Kết nối Database: Container Sidecar liên kết chung Docker Network với container coolify-db, cho phép đọc cấu hình project, uuid và decrypt biến môi trường (.env) bằng mã hóa AES-256-CBC.
  • Quản lý Docker socket: Bằng cách mount /var/run/docker.sock, daemon backup có thể khởi động các container Alpine phụ để sao lưu volume an toàn hoặc chạy dump DB trực tiếp từ container database đang hoạt động.
  • Giao diện Dashboard độc lập: Cung cấp UI cấu hình Google Drive OAuth qua trình duyệt, lưu trữ Token cục bộ và gọi lệnh CLI để chạy task định kỳ.

Cơ chế Quản lý Token & Session

Mô hình Google Drive OAuth sử dụng giao thức bảo mật hai giai đoạn:

  1. Authorization Code Flow: Người dùng đăng nhập qua cổng Google Cloud của riêng họ, xác nhận cho phép module backup quyền truy cập. Trình duyệt Redirect về container sidecar trả về Authorization Code.
  2. Token Exchange: Module gửi code lên Google API để lấy về access_token (hết hạn sau 1 tiếng) và refresh_token (vô hạn thời gian).
  3. Token Auto-Refresh: Khi CLI chạy tự động qua Cron, script Python sẽ tự kiểm tra hạn của token. Nếu hết hạn, nó sẽ thực hiện refresh token âm thầm trong background trước khi upload mà không làm gián đoạn tiến trình.

Sơ đồ Quy trình Hoạt động của Plugin/Module

💡 Đóng gói Docker Compose cho Plugin: Để triển khai, chỉ cần định nghĩa cấu hình sidecar trong file docker-compose.yaml chung network với Coolify, ánh xạ thư mục cấu hình và Docker Socket. Không làm ảnh hưởng tới hoạt động của bất cứ container nào hiện tại của bạn.

Mã nguồn CLI Đã Xây Dựng (Thực tế trên VPS)

Chúng tôi đã phát triển thành công bộ máy core CLI bằng ngôn ngữ Python, chạy ổn định, an toàn và tối ưu hóa bộ nhớ RAM thông qua cơ chế mount container trung gian và gọi API thuần không phụ thuộc thư viện nặng.

backup_tool.py Kích thước: 20 KB

Mã nguồn core điều phối toàn bộ quá trình sao lưu: Tự kết nối CSDL postgres của Coolify để trích xuất danh sách dự án, giải mã các biến env, quét các container đang hoạt động, chạy dump Database và nén toàn bộ docker volume.

token_manager.py Kích thước: 10.4 KB

Quản lý giao thức xác thực OAuth 2.0 với Google Drive API: Tự khởi tạo cổng HTTP callback tạm thời (port 8085) để hứng authorization code, thực hiện lưu trữ tokens.json mã hóa và tự động refresh token khi hết hạn.
