Tài Liệu Hướng Dẫn Kỹ Thuật

9Router Cấu Hình Tối Ưu

Giải thích nguyên lý định tuyến và hướng dẫn kết nối các công cụ Agentic CLI (Antigravity CLI, Cursor, Cline, OpenCode) hiệu quả nhất.

1 Chiến Lược Định Tuyến: Fallback vs Round-Robin

9Router hỗ trợ hai chiến lược chính để điều phối yêu cầu khi bạn cấu hình Combo (Mô hình kết hợp) hoặc Provider (Nhà cung cấp). Việc chọn sai chiến lược sẽ ảnh hưởng nghiêm trọng đến hiệu năng của các công cụ AI lập trình tự trị (Agent).

1. Chiến Lược: Fallback (Ưu Tiên Dự Phòng)

Khuyên Dùng Cho Agentic CLI

Nguyên lý: 9Router sẽ luôn gửi các yêu cầu đến Model đầu tiên trong danh sách. Chỉ khi Model 1 bị lỗi (hết lượt, mất kết nối), 9router mới tạm thời chuyển sang Model 2.

  • ✔ Giữ Prompt Caching: Tiết kiệm tới 90% chi phí token vì ngữ cảnh được lưu trên 1 máy chủ duy nhất.
  • ✔ Đồng nhất tư duy: Agent CLI không bị nhầm lẫn cú pháp gọi tool hay phong cách code giữa các câu trả lời.

2. Chiến Lược: Round-Robin (Xoay Vòng)

Không Nên Dùng Cho Khác Model

Nguyên lý: Mỗi yêu cầu tiếp theo sẽ tự động được gửi xoay vòng qua các Model/Tài khoản khác nhau, bất kể mô hình trước có bị lỗi hay không.

  • ✘ Phá hủy Prompt Caching: Token bị tính phí lại từ đầu cho mỗi lượt vì đổi máy chủ liên tục.
  • ✘ Gây lỗi ngữ cảnh (Context): CLI gửi một lịch sử hội thoại phức tạp, nhưng "não" nhận dạng của từng request liên tục bị thay đổi dẫn đến xung đột cú pháp công cụ.
💡 Đã cấu hình tự động: Tôi đã cấu hình lại toàn bộ hệ thống 9Router của bạn sang chiến lược `fallback` cho toàn bộ Combo và Providers. Hệ thống hiện đã được thiết lập tối ưu nhất cho lập trình tự động.

2 Cấu Hình Kết Nối Trên Máy Tính Local (Laptop)

Để trỏ các CLI cài ở máy tính cá nhân của bạn chạy qua 9Router tập trung ở VPS 162, hãy thực hiện cấu hình theo các thông số sau:

Cấu hình biến môi trường (.env / bashrc ở máy local)
# Địa chỉ endpoint của 9Router VPS 162
OPENAI_API_BASE="http://103.179.189.162:20128/v1"

# API Key của bạn (Sử dụng key đã được kích hoạt trên 9router)
OPENAI_API_KEY="sk-29a253ecb471306c-jjmryy-525c5e89"

Antigravity CLI

Cấu hình trong file ~/.antigravity/config.yaml hoặc xuất biến môi trường CLOUD_CODE_URL=http://103.179.189.162:20128 để trỏ luồng biên dịch và hỗ trợ của Gemini qua VPS.

Hermes CLI

Chỉnh sửa file cấu hình ~/.hermes/config.yaml để định vị provider 9router trỏ về địa chỉ IP của VPS 162 cùng API Key đã cấu hình.

Cursor / VS Code

Trong cài đặt Models của Cursor, thêm Base URL: http://103.179.189.162:20128/v1 và điền API Key để đồng nhất toàn bộ tài khoản lập trình.

3 Nguyên Tắc Vàng Khi Thiết Lập 9Router

1. Chỉ luân phiên xoay vòng (Round-robin) tài khoản CÙNG loại:
Nếu bạn có 5 tài khoản GitHub Copilot, bạn có thể thiết lập Round-robin để tránh chạm giới hạn Rate Limit của một tài khoản. Do chúng đều dùng chung một mô hình xử lý, chất lượng câu trả lời sẽ không bị ảnh hưởng.
2. Luôn dùng dự phòng (Fallback) đối với KHÁC loại mô hình:
Khi gom nhóm Claude 3.5 và Gemini 3.5 vào cùng một Combo, luôn luôn dùng chiến lược Fallback. Đặt model bạn muốn làm việc chính lên dòng đầu tiên. Chỉ khi có lỗi hệ thống, 9router mới tự động chuyển đổi.
3. Quản lý tập trung:
Hạn chế tối đa việc đổi API keys hoặc import tài khoản lặt vặt trên máy tính cá nhân. Hãy lưu tất cả thông tin đăng nhập trên 9Router VPS 162. Khi có tài khoản mới, chỉ cần khai báo một lần tại 9Router.
